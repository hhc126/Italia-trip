# 🇮🇹 意大利之旅行程单

2026年7月意大利之旅行程单，支持 iPhone 上作为 Web App 使用。

## 功能

- 🗓️ 7月11日-23日完整行程（索伦托→罗马→佛罗伦萨→威尼斯→米兰）
- 📍 GPS 自动定位当前城市，高亮 + 自动滚动
- 🕐 实时当地时间
- 🌅🌇 日出日落时间（NOAA 公式离线计算）
- 🌡️ 天气预报（Open-Meteo API）
- 📱 支持 iPhone「添加到主屏幕」，全屏 App 体验
- 🔌 完全离线可用（天气需网络）

## 文件结构

```
意大利之旅/
├── 意大利行程单.html      ← 源文件（编辑这个）
├── images/               ← 城市背景图
├── deploy/               ← 部署版（自动生成，图片内嵌）
├── tests/                ← GPS 定位测试
├── archive/              ← 历史文件
├── build.sh              ← 打包部署脚本
└── .gitignore
```

## 在线访问

行程单已部署到 CloudStudio，iPhone Safari 直接打开链接即可使用。
